   → Processes ONLY the 4 pending repos (not all 319)
   → Progress bar: 1/4, 2/4, 3/4, 4/4

   → Fetches ALL links from bot
   → Checks each against vault
   → Shows: "319 in bot → 319 in vault ✅ → 0 missing ❌"
   → If 0 missing: asks "Mark all as read?" → clears queue
   → Badge turns green: "✅ 0 pending"

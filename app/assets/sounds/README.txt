GitCurator sound assets
=======================

success.wav — the batch-finish chime (v0.39.0). A soft ascending major
arpeggio (E5 -> G5 -> C6), ~1 second, 44.1 kHz / 16-bit / mono PCM —
played through Qt's QSoundEffect the moment a batch runs to natural
completion with no failed links (alongside the success modal).

retry.wav — the needs-retry variant (v0.40.0). A softer DESCENDING
two-tone (C6 -> G5), ~0.7 seconds, same format — played when a batch
finishes WITH failed links, so "done, but look at me" never sounds
like a celebration. The file's own normalized peak is lower (~0.45 vs
success.wav's ~0.72): the softness is baked into the asset, so ONE
user volume applies to both voices and the Settings preview is the
truth.

Provenance: BOTH files are SYNTHESIZED, not sampled — generated by a
small script (sine partials + exponential envelopes, no third-party
material), so there are no licensing restrictions of any kind.
Regenerate with the same parameters if a different tone is ever
wanted.

Config keys (Settings -> Sound since v0.40.0; config.json before):
  "sound_enabled": true   — master switch (default true; one switch
                            governs BOTH voices)
  "sound_volume": 0.8     — 0.0..1.0, applied on top of each file's
                            own normalized peak; clamped into Qt's
                            [0, 1] on read, on save, and on play

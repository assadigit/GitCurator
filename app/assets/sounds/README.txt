GitCurator sound assets
=======================

success.wav — the batch-finish chime (v0.39.0). A soft ascending major
arpeggio (E5 -> G5 -> C6), ~1 second, 44.1 kHz / 16-bit / mono PCM —
played through Qt's QSoundEffect the moment a batch runs to natural
completion (alongside the success modal).

Provenance: SYNTHESIZED, not sampled — generated by a small script
(sine partials + exponential envelopes, no third-party material), so
there are no licensing restrictions of any kind. Regenerate with the
same parameters if a different tone is ever wanted.

Config keys (config.json, no Settings UI yet):
  "sound_enabled": true   — master switch (default true)
  "sound_volume": 0.8     — 0.0..1.0, applied on top of the file's own
                            normalized peak (~0.72)

# About Me

I am a software engineer and researcher focused on AI agents, developer tools, and automation. I curate GitHub projects to build a personal knowledge base of useful tools and frameworks.

- Find AI agent frameworks and MCP servers I can integrate into my projects
- Identify self-hostable alternatives to SaaS products
- Learn about new approaches to scraping, automation, and infrastructure

## My interests
- AI/LLM tooling (agents, skills, MCP, prompt engineering)
- Developer productivity tools
- Self-hosted software and homelab infrastructure
- Open-source projects from major tech companies
- Automation and workflow orchestration

## How I use this knowledge base
I organize curated projects into an Obsidian vault categorized by domain (AI-Domain, Tools, Frameworks, Infrastructure). Each note helps me quickly recall what a project does, how it works, and whether it's credible enough to adopt.
